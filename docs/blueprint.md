# **App Name**: SwiftBiz

## Core Features:

- Dashboard Overview: Display a scannable summary of money in vs. money out for the current month, unpaid invoices, and pending actions.
- AI Alert System: Provide quick alerts powered by AI to identify critical issues like 'Low cash' or '3 overdue tasks.' The alerts system uses a tool to detect when conditions require a low cash or overdue task alerts. The tool intelligently combines this analysis with task status and amounts of cash and overdue tasks to choose what, if anything, to alert.
- Task Management: Create tasks, assign them to users, and set due dates and status updates.
- Task Filters: Implement simple filters for tasks, such as 'Today,' 'Overdue,' and 'Completed.'
- Income/Expense Tracking: Add and track income and expenses, categorized for better organization.
- Monthly Summary: Generate a monthly summary of income and expenses.
- Client Management: Maintain a client list with contact info, notes, and linked tasks & payments.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and stability, reminiscent of established financial institutions.
- Background color: Light gray (#F0F2F5), a desaturated version of the primary color for a clean and modern look.
- Accent color: Vibrant orange (#FF9800) to highlight key actions and alerts.
- Font pairing: 'Inter' for body text (sans-serif) to ensure readability and 'Belleza' for headlines (sans-serif) for an elegant touch; choosing 'Alegreya' for body text in places requiring longer text passages
- Use a consistent set of minimalist icons to represent categories, tasks, and financial data. Use a weight and style which is consistent with the chosen font(s).
- Maintain a clean and scannable layout with clear sections for each feature, prioritizing key information on the dashboard.
- Subtle transitions and animations to enhance user experience without being distracting, like when adding/editing info.
